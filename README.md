# 螺杆长度自动计算工具

按被固定物厚度自动计算并选用标准螺栓长度，附带套筒规格查询，适合现场快速选型。

- 当前版本：**1.1.7**
- 平台：Android（4.4 及以上）
- 作者：文仔大大
- 邮箱：876972085@qq.com

## 功能

- 螺栓规格 M3–M20 下拉选择，自动带出对应固定值
- 厚度支持直接填整数，也支持算式（如 `2+5`），自动求和
- 计算值按规则取整：个位 1–2 归零、3–7 取 5、8–9 进位到 10
- 同时显示对应套筒规格（双规格时第一个绿色、第二个黄色）
- 一键复制规格；复制过的规格自动记录，可改数量、逐条删除、一键清空
- 按「总数」批量计算用量并复制
- 启动时自动检测新版本，可直接跳转下载
